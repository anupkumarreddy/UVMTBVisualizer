# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's private **Report a vulnerability** flow on the repository's Security tab so the report can be assessed before details are published.

Include the affected version or commit, reproduction steps, expected impact, and any suggested mitigation. You should receive an initial response within seven days.

## Data handling

The application reads the log file selected by the user and processes it locally. It has no backend service and does not upload the selected log. Users should still avoid sharing proprietary simulator logs in public issues or test fixtures.
